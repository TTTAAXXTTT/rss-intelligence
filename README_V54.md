# RSS 内容系统 V5.4

V5.4 把公开订阅改成严格的 48 小时中文全文视图：公开出现的每条文章都必须带一个仍有效的中文全文阅读页，任何缺失、摘要替代、截断或校验失败都会阻止该期发布。

## 公开订阅

- `all.xml`：48 小时内全部已完成中文全文的内容。
- `priority.xml`：上述内容中的 S 级或高价值机会。
- `reports.xml`：48 小时内的完整报告，每条信息含总结、重要性、影响、原文和中文全文链接。
- `brief.xml`：48 小时内的精简报告，每条信息只保留一句话和中文全文链接。

文章订阅的 RSS `<link>` 始终是原文地址，中文全文地址只放在正文中。阅读页使用不可枚举的私有路径、禁止索引和缓存，并在首次生成 48 小时后自动移除；重试或重放不会延长有效期。

## 完整性规则

翻译清单必须与当期最终条目逐项一致，且每项均满足 `status=complete`、`sourceCompleteness=full`、`truncated=false`、页面哈希一致。系统不再接受 partial、limited、classified-summary 或空清单降级发布。

抓取顺序为原站正文、备用来源、只读正文提取服务、FreshRSS 在线条目、FreshRSS 本机数据库中的精确 URL 条目，最后才使用当期不可变快照中明确标记为“未截断”的完整订阅内容。后三种方式会在页面上说明“订阅源提供的全部正文内容”，不会把分类摘要或被截断的快照伪装成全文；数据库只通过 `PRAGMA query_only=ON` 和绑定查询读取。

## 到期处理

清理任务每分钟先重新生成四个公开订阅、移除已到期文章和报告，再删除对应阅读页。内部结构化归档仍保留用于审计，但不会以无全文链接的形式继续出现在公开订阅中。

## 故障处理

单条抓取或翻译失败时会保存已验证的私有进度并重试缺失项；整期只有达到精确覆盖才会发布。失败不会写空翻译清单，也不会更新成功水位。
